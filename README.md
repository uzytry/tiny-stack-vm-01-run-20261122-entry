# tiny-stack-vm-01

A tiny stack VM for [make.fun's tiny-stack-vm-01 bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one program answers all 40 instances, each a bytecode program of the tiny stack ISA v1, with exactly the bytes it writes and the exit code it ends with. A faithful port of the kit's reference VM, including all ten traps, the step and output limits, and every hard rule in ISA.md.
